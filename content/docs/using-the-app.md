# Using the app

## Check activation

Choose **Check status**. The app runs the Windows Software Licensing Management Tool and displays its response.

## Open Activation settings

Choose **Open Activation settings** to open the built-in Windows page at **Settings → System → Activation**. Use the Activation troubleshooter there when available.

## Install a licensed product key

1. Run the app as administrator.
2. Enter a genuine product key that you are authorized to use.
3. Choose **Install key and activate**.
4. Review the confirmation prompt and the response from Windows.

The key is passed to the local Windows licensing script and is not saved to a project file. Keep it private.
